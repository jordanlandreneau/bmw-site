## Parts Directory

> **Follow the Parts Call process on every call**
>
> **PARTS CALL PROCESS — Ask customer if they are trying to:**
>
> 1. (A) Order and install a part
>     - If option (A) ===> them schedule a service appt,
> 2. (B) Just order a part.
>     - If option (B) ===> send to parts
>
> **Ask customer if they have already ordered a part, if so…**
>
> 1. (A) if they ordered with service advisor on drive
>     - If option (A) ===> send to service advisor working on car
> 2. (B) if they if they ordered via parts directly.
>     - If option (B) ===> send to parts.
>
> Any inquiring that the BDC needs to make about parts availability to book the appt they can contact the service advisor first and, if unreachable, then parts directly and ask availability without transferring customer. Preference to contact Jim or Alex first.
